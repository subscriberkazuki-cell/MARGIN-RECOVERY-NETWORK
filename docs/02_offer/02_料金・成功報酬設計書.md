# 料金・成功報酬設計書

【判断】料金は3段階。無料で引き受ける作業量に上限を設ける。

## 1. 料金体系

| 段階 | 商品 | 価格（税別） | 無料作業の上限 / 条件 |
|---|---|---|---|
| 1 | 無料診断 | 0円 | 出荷CSV1か月分＋契約料金表の提出が条件。自動突合＋人手15分以内。結果は「確定過請求額」と「改善余地レンジ」のみ提示し、具体的な施策は本監査で開示 |
| 2 | 本監査（MARGIN AUDIT for EC） | 成功報酬 25% × 12か月分 | 着手金なし。改善余地が月3万円未満と診断された場合は本監査を勧めない |
| 2' | 固定料金オプション | 98,000円（成功報酬から全額控除） | 顧客が成功報酬の算定（データ継続提出）を望まない場合のみ |
| 3 | MARGIN WATCH | 月額 19,800円〜（別紙） | 成功報酬の対象期間中は初月から3か月無料で併用可（解約率を測るため） |

## 2. 報酬率の根拠と見直し基準

- 25%は、顧客が12か月で削減額の75%、13か月目以降は100%を得る水準。【仮説】国内の成果報酬型コスト削減は報酬率がこれより高いことが多いとされるが**公式な相場データは未確認**。最初の10社で以下を計測し調整する。
  - 成約率が50%を超え、値下げ要求がほぼない → 30%に引き上げを検討
  - 「報酬が高い」を理由とした失注が30%超 → 20%＋算定期間18か月を検討
- 1社あたり報酬が10万円を下回る見込みの案件は受けない（作業時間に見合わない）。

## 3. 請求・入金フロー

1. 効果検証レポートを顧客が承認（メール返信で可、記録保存）
2. 請求書発行（適格請求書発行事業者の登録が必要か税理士に確認）
3. 支払期限：請求月の翌月末、銀行振込
4. 2回目（50%）は3か月後の再検証で精算。差異がある場合は増減精算
5. 支払遅延30日で督促、60日で以後のサービス停止。回収不能見込み5%を収益計画に織り込み済み

## 4. 価格表示ルール（景品表示法対応）

- 「平均◯%削減」「最大◯万円削減」等は実績が出るまで掲載しない
- モデルケースは「架空の計算例」と明記し、前提条件（出荷数・単価）を併記
- 「完全成果報酬」と表示する場合、成功報酬以外に費用が発生しないことを利用規約で担保（固定料金オプションは顧客が選択した場合のみと明記）
