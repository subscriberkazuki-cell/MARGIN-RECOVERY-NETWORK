# 料金・成功報酬設計書（v0.2：2026-11-10 経営判断を反映）

**弁護士レビュー完了まで、成功報酬の請求・有償契約の締結はしない。** 本書の料率・算定式は叩き台。

| 段階 | 商品 | 価格（税別） | 条件 |

| 0 | ヒアリング（W1〜3） | — | 売り込みなし。データは受け取らない |

## 2. 算定例（3パターン・架空）

区分別単価差は、同一サイズ・同一地域区分・同一サービスで比較する。

| | 小規模 | 標準 | 大規模 |
|---|---:|---:|---:|
| 月間出荷数 | 1,000件 | 2,500件 | 10,000件 |
| 改善の内容 | 薄型商品150件を小型便へ（1個あたり380円減） | 小型便化300件（380円減）＋サイズ是正200件（210円減） | 小型便化1,200件（380円減）＋残り8,800件の運賃単価改定（25円減） |
| 当月の削減額 | 57,000円 | 156,000円 | 676,000円 |
| 当月の成功報酬（25%） | 14,250円 | 39,000円 | 169,000円 |
| 12か月で同水準が続いた場合の報酬合計 | 171,000円 | 468,000円 | 2,028,000円 |
| 顧客に残る削減額（同12か月） | 513,000円 | 1,404,000円 | 6,084,000円 |

計算：小規模＝150×380＝57,000円。標準＝300×380＋200×210＝156,000円。大規模＝1,200×380＋8,800×25＝456,000＋220,000＝676,000円。
※ 同じ出荷を2つの施策に重ねて計上しない（大規模例では小型便化した1,200件を単価改定の対象から除いている）。

## 3. 報酬率25%の見直し基準

- 国内の成果報酬型コスト削減の報酬率相場は未確認。ヒアリングで「成果をどう定義してほしいか」「何%なら払うか」を聞く
- 本監査の成約率が50%超で価格への異論がほぼない → 30%を検討
- 「報酬が高い」を理由とする失注が30%超 → 20%＋対象期間18か月を検討
- 1社あたり月次報酬が1万円を下回る見込みの案件は受けない

## 4. 請求・入金フロー（弁護士レビュー後に確定）

1. 毎月、顧客から当月の宅配便請求明細を受領（WATCH顧客は同じデータで兼用）
2. 区分別に「実出荷数 × 実際に適用された削減単価」を算定し、算定表を顧客に送付
3. 顧客の確認期間（例：7日）。異議があれば根拠を照合し、合意できない部分は請求しない
4. 請求書発行（適格請求書発行事業者の登録要否は税理士に確認）、支払期限は翌月末
5. 最大12か月で終了。WATCH契約がある場合はWATCHに移行

## 5. 価格表示ルール（景品表示法対応）

- 実績が出るまで「平均◯%削減」「最大◯万円削減」は掲載しない
- モデルケースは「架空の計算例」と明記し前提条件を併記
- 収益シミュレーションは経営目標の試算であり、対外的に予測実績として表示しない
