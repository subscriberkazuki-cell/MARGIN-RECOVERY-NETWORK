# TASK 3：初期サービスの決定

【判断】最初に売るサービスは1つだけ：

## 商品名：MARGIN AUDIT for EC — 配送費・物流請求監査

> 「出荷データと請求書を突き合わせ、払いすぎている配送費を根拠付きで特定し、削減を実現した分だけ報酬をいただく」

---

## 1. 定義

| 項目 | 内容 |
|---|---|
| 顧客 | 年商1〜10億円のEC事業者（自社EC・モール出店）。月間出荷1,000〜20,000件。自社出荷または3PL委託 |
| 意思決定者 | 代表者、EC責任者、物流・オペレーション責任者 |
| 監査対象（3つに限定） | ①宅配運賃（契約単価との突合・サイズ区分・配送サービス選択）②3PL請求（保管・入出庫・作業費の契約条件との突合）③決済手数料（料率・決済構成の確認） |
| 対象外 | 運送会社・3PLとの交渉代理、返金請求の代理、契約締結の代理、税務判断 |
| 価格 | 無料診断：0円／本監査：着手金0円、成功報酬＝**実現削減額（12か月分）の25%（税別）** |
| 最低報酬・上限 | 最低報酬なし（成果ゼロなら請求ゼロ）。上限：1社あたり税別300万円【仮説・検証後調整】 |
| 納品物 | ①一次診断結果（自動）②監査レポート（根拠明細付き）③改善施策リストと業務影響評価④見積比較表（顧客名義で取得）⑤効果検証レポート |
| 期間 | 診断1週間 → 本監査2週間 → 顧客による改善実行2〜6週間 → 効果検証（実行後1か月の実績） |
| 想定作業時間 | 診断1h／本監査6h／改善支援・検証4h（合計約11h） |

## 2. 成功報酬の算定方法（単価差方式）

出荷量の増減で報酬が歪まないよう、**「単価差 × 実数量」**で算定する。

```
月間削減額 = Σ（変更前の契約単価 − 変更後の契約単価）× 当月の実出荷数（区分別）
成功報酬   = 検証月の月間削減額 × 12 × 25%
```

| 削減の種類 | 算定方法 | 報酬の請求タイミング |
|---|---|---|
| 運賃単価の改定（顧客が交渉・相見積で実現） | 区分別単価差 × 検証月の区分別実出荷数 × 12 | 検証完了時50%、3か月後の再検証時50%（再検証で差異があれば精算） |
| 配送サービスの変更（小型便化など） | 対象商品の単価差 × 検証月の対象出荷数 × 12 | 同上 |
| 運送会社・3PLの切替 | 新旧の総コスト差（作業費・保管料を含む）× 12。切替費用（初期費用・移管費）は差し引く | 同上 |
| 過請求の判明（重複・契約単価超過・サイズ誤り） | 顧客が実際に返金・相殺を受けた金額 × 25%（12倍しない） | 返金・相殺の確認後 |
| 決済手数料の料率改善 | 料率差 × 検証月の決済額 × 12 | 同上 |

### 二重計上・過大請求の防止ルール

1. 同じ出荷・同じ費目は1つの施策にのみ計上（施策の重なりは小さい方を採用）
2. 運送会社が一律に実施した値下げ・キャンペーン等、当社の提案と無関係な削減は対象外
3. 顧客が当社の診断前から交渉中だった案件は、契約時の申告により対象外
4. 削減の代わりにサービス品質が下がる施策（遅延・破損率上昇）は、顧客の書面同意がある場合のみ実施・計上
5. 当社がベンダーから手数料を受け取った場合は全額開示し成功報酬から差し引く（原則受け取らない）

## 3. 単位経済性（1社あたり・標準仮定）

| 項目 | 金額 |
|---|---:|
| 月間配送費 | 1,000,000円（出荷1,250件×800円）【仮説】 |
| 削減率 | 8% → 月80,000円【仮説】 |
| 成功報酬 | 80,000 × 12 × 25% = **240,000円** |
| 直接費用 | AI・API・OCR 3,000円＋作業11h（創業者時給換算は除外） |
| 粗利益率 | 約99%（人件費除く）。創業者時給5,000円換算でも約76% |
| 顧客の正味利益（12か月） | 960,000 − 240,000 = **720,000円**、13か月目以降は削減額の100%が顧客に残る |

## 4. なぜこの商品か（他の候補の却下理由）

| 候補 | 却下理由 |
|---|---|
| 汎用「固定費まるごと見直し」 | 対象が広すぎてルール化・自動化できない。1件ごとに調査がゼロから |
| 美容室向け決済・集客費の見直し | 1社あたり報酬3〜9万円で採算割れ（TASK1参照） |
| 電気料金の見直し | 低圧は燃料費調整制度・料金支援策で単価が月ごとに動き、削減額の証明が難しい。市場連動プランは高騰リスクがある（東京電力PG・関西電力の公表資料）。販売代理店との競合も激しい |
| SaaS棚卸し | Admina等が50ID以下を無料で提供しており価格競争になる |
| 複合機リース | 中途解約は原則不可で残債一括請求の事例も多く、削減が満了時期に依存する |

これらは Phase 6 で MARGIN WATCH のチェック項目として追加する（単独商品にはしない）。
