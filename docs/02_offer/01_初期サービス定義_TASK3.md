## 商品名：MARGIN AUDIT for EC — 宅配便請求監査

> 「宅配便の請求明細を契約運賃表と照合し、差異と改善候補を根拠付きで示す。改善が実際の請求に反映された分だけ、報酬をいただく」

## 1. 定義

| 項目 | 内容 |
|---|---|
| 顧客 | 年商1〜10億円のEC事業者。月間出荷1,000〜20,000件。宅配便を直接契約または3PL経由で利用 |
| 監査範囲（標準） | 宅配便の請求明細と契約運賃表の照合のみ。監査エンジンが対応する4項目：①重複請求 ②契約単価を超える請求 ③実寸・実重量に比べて大きいサイズ区分の候補 ④小型配送便への切替候補 |
| 第2段階（標準範囲外） | 3PL請求（保管・入出庫・作業・資材・返品・最低利用料）、決済手数料。**専用のデータ仕様・判定基準・テストが揃うまで「監査対応済み」として販売しない**。ヒアリングでニーズのみ確認する |
| 当社が行うこと | データの集計、契約単価との照合、数値上の差異の提示、代替プランの情報整理、顧客が自ら見積を取るための資料作成支援 |
| 当社が行わないこと | 運送会社・3PLとの交渉の代理、返金請求、債権回収、和解・示談、契約解除・紛争対応、当社名義または代理人名義での相手方への文書送付 |
| 価格 | 無料診断：0円／本監査：着手金0円、成功報酬＝**実際に請求へ反映された削減額の25%（税別）を、反映月から最大12か月、月次後払い**（25%は仮置き。算定式は弁護士レビュー後に確定） |
| 納品物 | ①照合結果（確定／要確認／推定）②改善候補リストと業務影響の整理 ③顧客が見積を取るための資料 ④月次の効果確認レポート |
| 想定作業時間 | 診断1h／本監査6h／効果確認 月0.5h（合計 約8〜12h） |

## 2. 成功報酬の算定（叩き台）

```
当月の成功報酬 = 25% × Σ（当月の実出荷数[区分別] × 当月に実際に適用された1個当たり削減額[区分別]）
対象期間     = 削減単価が実際に請求へ反映された月から最大12か月
```

| 原則 | 内容 |
|---|---|
| 実績ベース | 将来予測（×12）での一括請求はしない。毎月の請求書で反映を確認できた分のみ |
| 対象は「当社が特定し、顧客が採用し、実請求に反映された」削減 | 3条件のいずれかを欠けば対象外 |
| 構成変化の調整 | 出荷先・サイズ・配送サービス・商品構成が変わった場合、単純な単価差で計算しない（区分別に同一条件で比較） |
| 追加料金 | 燃料サーチャージ・繁忙期加算・離島料金・税・値引き・リベートは、契約で明示したものだけを算入 |
| 反映されなければ0円 | 削減が請求に反映されなかった月は報酬なし |
| 過請求の返金・相殺 | 顧客自身が照会し実際に受けた金額。報酬対象にするかは弁護士レビューで判断（非弁リスクが最も高い論点） |

## 3. 単位経済性（1社あたり・標準仮定）

| 項目 | 金額 |
|---|---:|
| 月間配送費 | 1,000,000円（出荷1,250件×800円）【仮説】 |
| 反映された削減 | 8% → 月80,000円【仮説】 |
| 月次の成功報酬 | 80,000 × 25% = 20,000円/月 × 最大12か月 = 最大240,000円 |
| 直接費用 | AI・API等 3,000円＋作業 約10h |
| 創業者時給5,000円換算の粗利益率 | 約78% |

**注意：月次後払いのため、報酬の受領は削減反映の翌月から12か月に分散する。** 立ち上がりが遅くなる影響は `docs/06_plan/02_収益シミュレーション結果.md` を参照。

## 4. 他の候補を却下・後回しにした理由

| 候補 | 判断 |
|---|---|
| 3PL請求監査 | 第2段階。施設・契約ごとの項目差が大きく、専用ロジックとテストが必要 |
| 決済手数料 | 第2段階。ブランド・決済手段・返金・固定費の条件差が大きい |
| 電気料金 | 却下。低圧は燃料費調整・料金支援策で単価が動き、削減の証明が難しい |
| SaaS棚卸し | 却下。無料ツールと価格競争になる |
| 複合機リース | 却下。中途解約が原則不可で、削減が満了時期に依存する |
| 美容室向け | 却下（TASK1）。代理店経由の自動診断として Phase 6 で再検討 |
