# 成功報酬契約の論点整理（弁護士レビュー用）

> 本書は法的助言ではない。弁護士・税理士に確認する論点の整理。**契約書は専門家レビュー完了まで顧客と締結しない。**
> v0.2（2026-11-10）：経営判断により、成功報酬は「実際に請求へ反映された削減額の月次実績」ベースに変更。監査範囲は宅配便請求に限定。依頼資料一式は `docs/legal/` を参照。

## 弁護士レビュー完了まで禁止すること

- 成功報酬の請求、有償契約の締結
- 返金請求・交渉の代理、顧客に代わる契約変更交渉
- 法的紛争に踏み込む助言
- 顧客の実データ（請求明細・契約運賃表・出荷CSV）の受領（ヒアリングは口頭の一般的な課題確認に限定）

**注意**：業務名を「分析」「事務支援」と書くだけで適法になるわけではない。実際の行為・相手方との紛争可能性・報酬との関係で判断されるため、具体的な業務フローを提示し、許容範囲と禁止行為を文章で回答してもらう。

## A. 最重要：業務範囲と弁護士法72条（非弁行為）

| 論点 | 当社の設計案 | 確認したいこと |
|---|---|---|
| A-1 業務範囲 | 「支出データの分析」「改善提案」「顧客名義での見積取得手続の事務支援」に限定。運送会社・3PLとの**交渉、返金請求、契約変更の代理は行わない** | この範囲が「法律事件に関する法律事務」に該当しないか |
| A-2 過請求の返金 | 当社は根拠資料（追跡番号・契約単価・差額）を作成するのみ。照会・請求は顧客自身が行う。報酬は顧客が実際に受けた返金額の25% | 返金額連動の報酬が、実質的な請求代行とみなされないか。紛争性がない単なる請求誤りの照会は「事件性」がないと整理できるか |
| A-3 相見積の取得 | 顧客の委任に基づき、顧客名義で複数社に見積依頼を送る | 見積依頼・条件確認の連絡は交渉に当たるか。当社名義で連絡する場合との違い |
| A-4 紛争化した場合 | 相手方が支払・返金を拒否した時点で当社は関与を終了し、弁護士への相談を顧客に勧める（**弁護士の有償紹介はしない**） | 終了条項の書き方 |

参考：債務整理の和解交渉を非弁護士が回収額の30%を手数料として行った事例で72条違反とされた裁判例（東京地判平成21年4月13日、解説記事より）。

## B. 成果の定義と算定

叩き台の算定式（正式採用は弁護士レビュー後）：

`当月の成功報酬 = 25% × Σ（当月の実出荷数 × 当月に実際に適用された1個当たり削減額）`（区分別、反映月から最大12か月）

| 論点 | 設計案 |
|---|---|
| B-1 基準 | 基準となる契約単価・請求単価・対象サービス・対象期間を個別契約の別紙で特定（契約締結日時点の運賃表を添付） |
| B-2 反映の証拠 | 改定後の請求書・料金表で「実際に適用された」ことを確認できた月のみ対象 |
| B-3 出荷数 | 月ごとの実績（年合計や予測は使わない） |
| B-4 追加料金 | 燃料サーチャージ、繁忙期加算、離島料金、税、値引き、リベートは、契約で明示したものだけ算入 |
| B-5 構成変化 | 配送量・商品構成・配送先構成・契約条件が変わった場合、区分別に同一条件で比較し、単純な単価差で計算しない |
| B-6 成果の帰属 | 「当社が特定し、顧客が採用し、実請求に反映された」削減のみ。顧客が独自に交渉した場合・関与前から交渉中だった場合・運送会社の一律値下げ・複数の支援会社が関与した場合の扱い |
| B-7 二重計上 | 同一出荷を複数施策に重ねて計上しない |
| B-8 請求時期・支払 | 月次後払い、支払期限、返金・取消し・過払いの調整方法 |
| B-9 確認と異議 | 顧客による算定根拠の確認方法と異議申立て期間（例：算定表送付後7日） |
| B-10 データ提供 | 算定に必要な請求データの提出が止まった場合の扱い |
| B-11 途中解約 | 解約時点で反映済みの削減について、残期間の報酬をどう扱うか |
| B-12 過請求の返金 | 顧客自身が照会し受けた返金・相殺を報酬対象にしてよいか（非弁リスクが最も高い。対象外とする選択肢を含めて意見を求める） |

## C. 責任・保証

| 論点 | 設計案 |
|---|---|
| C-1 非保証 | 削減額を保証しない。診断結果は提出データに基づく推定 |
| C-2 責任上限 | 受領済み報酬額を上限 |
| C-3 業務影響 | 配送サービス変更による遅延・破損・顧客満足度低下のリスクは事前に書面で説明し、実行判断は顧客 |
| C-4 違約金 | 既存契約の解約違約金・最低利用期間は施策評価で必ず考慮し、総コスト差で算定 |

## D. データ・個人情報

| 論点 | 設計案 |
|---|---|
| D-1 個人情報 | 出荷CSVの届け先氏名・住所・電話は**提出前に削除を依頼**。必要なのは追跡番号・サイズ・重量・届け先都道府県・金額のみ。削除されずに届いた場合は受領後すぐにマスキング |
| D-2 委託先 | AIサービス（API）への送信は、学習に利用されない契約条件のサービスに限定。委託先一覧をプライバシーポリシーに記載 |
| D-3 保管・削除 | 顧客ごとに分離した保管領域。契約終了後90日で削除（会計上必要な請求関連書類を除く） |
| D-4 ベンチマーク利用 | 匿名化・集計した単価データの利用について個別同意を取る（オプトイン） |
| D-5 守秘 | 相互の秘密保持条項。運送会社との契約単価は顧客の営業秘密として扱う |

## C2. 契約書一式（整備を依頼）

1. 業務委託基本契約書・個別申込書（個別契約書）
2. 成功報酬条項・算定別紙
3. 秘密保持契約（または条項）
4. 個人データ等を取り扱う場合のデータ処理・安全管理条項
5. MARGIN WATCH 利用規約・月額契約・解約条件
6. プライバシーポリシー・問い合わせ表示・営業メール文面
7. 損害賠償の範囲・上限、免責、再委託、データ削除、事故報告、契約終了後の取扱い

## E. 税務・会計（税理士確認）

- 適格請求書発行事業者の登録要否（顧客は法人中心のため登録を推奨）
- 成功報酬の収益計上時期（検証完了時か、再検証時か）
- 紹介パートナーへの紹介料の処理

## F. 下請・取引関係

- 当社が業務の一部を外部に再委託する場合の取適法（中小受託取引適正化法、2026年施行）の適用有無
- 紹介パートナー契約（紹介料20%）の書式

## 依頼方法

- `docs/legal/01_弁護士見積依頼書.md` と本論点表を添えて、IT・事業法務を扱う弁護士2〜3名にスポット見積を依頼（予算15〜30万円【仮説】）
- 必要書類：利用規約、成功報酬契約書、秘密保持契約、プライバシーポリシー、紹介パートナー契約
