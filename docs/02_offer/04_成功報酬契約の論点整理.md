# 成功報酬契約の論点整理（弁護士レビュー用）

> 本書は法的助言ではない。弁護士・税理士に確認する論点の整理。**契約書は専門家レビュー完了まで顧客と締結しない。**

## A. 最重要：業務範囲と弁護士法72条（非弁行為）

| 論点 | 当社の設計案 | 確認したいこと |
|---|---|---|
| A-1 業務範囲 | 「支出データの分析」「改善提案」「顧客名義での見積取得手続の事務支援」に限定。運送会社・3PLとの**交渉、返金請求、契約変更の代理は行わない** | この範囲が「法律事件に関する法律事務」に該当しないか |
| A-2 過請求の返金 | 当社は根拠資料（追跡番号・契約単価・差額）を作成するのみ。照会・請求は顧客自身が行う。報酬は顧客が実際に受けた返金額の25% | 返金額連動の報酬が、実質的な請求代行とみなされないか。紛争性がない単なる請求誤りの照会は「事件性」がないと整理できるか |
| A-3 相見積の取得 | 顧客の委任に基づき、顧客名義で複数社に見積依頼を送る | 見積依頼・条件確認の連絡は交渉に当たるか。当社名義で連絡する場合との違い |
| A-4 紛争化した場合 | 相手方が支払・返金を拒否した時点で当社は関与を終了し、弁護士への相談を顧客に勧める（**弁護士の有償紹介はしない**） | 終了条項の書き方 |

参考：債務整理の和解交渉を非弁護士が回収額の30%を手数料として行った事例で72条違反とされた裁判例（東京地判平成21年4月13日、解説記事より）。

## B. 成果の定義と算定

| 論点 | 設計案 |
|---|---|
| B-1 削減額の定義 | 単価差×実数量。基準単価＝契約締結日時点の契約単価（請求書で確認） |
| B-2 算定期間 | 12か月相当額を検証月の実績から算定し、2回払い（検証時50%・3か月後の再検証時50%で精算） |
| B-3 対象外の削減 | 当社関与前から交渉中の案件、運送会社の一律値下げ、顧客の事業縮小による減少 |
| B-4 顧客が施策を実行しない場合 | 報酬なし。ただし当社提案を採用せず同内容を独自に実行した場合（提案後12か月以内）は報酬対象とするか → **要検討（紛争の種になりやすい）** |
| B-5 データ提供義務 | 検証に必要な請求データの提出を顧客の義務とし、提出がない場合は固定料金オプション相当額を請求できるか |
| B-6 途中解約 | 実行済み施策の報酬は解約後も発生 |

## C. 責任・保証

| 論点 | 設計案 |
|---|---|
| C-1 非保証 | 削減額を保証しない。診断結果は提出データに基づく推定 |
| C-2 責任上限 | 受領済み報酬額を上限 |
| C-3 業務影響 | 配送サービス変更による遅延・破損・顧客満足度低下のリスクは事前に書面で説明し、実行判断は顧客 |
| C-4 違約金 | 既存契約の解約違約金・最低利用期間は施策評価で必ず考慮し、総コスト差で算定 |

## D. データ・個人情報

| 論点 | 設計案 |
|---|---|
| D-1 個人情報 | 出荷CSVの届け先氏名・住所・電話は**提出前に削除を依頼**。必要なのは追跡番号・サイズ・重量・届け先都道府県・金額のみ。削除されずに届いた場合は受領後すぐにマスキング |
| D-2 委託先 | AIサービス（API）への送信は、学習に利用されない契約条件のサービスに限定。委託先一覧をプライバシーポリシーに記載 |
| D-3 保管・削除 | 顧客ごとに分離した保管領域。契約終了後90日で削除（会計上必要な請求関連書類を除く） |
| D-4 ベンチマーク利用 | 匿名化・集計した単価データの利用について個別同意を取る（オプトイン） |
| D-5 守秘 | 相互の秘密保持条項。運送会社との契約単価は顧客の営業秘密として扱う |

## E. 税務・会計（税理士確認）

- 適格請求書発行事業者の登録要否（顧客は法人中心のため登録を推奨）
- 成功報酬の収益計上時期（検証完了時か、再検証時か）
- 紹介パートナーへの紹介料の処理

## F. 下請・取引関係

- 当社が業務の一部を外部に再委託する場合の取適法（中小受託取引適正化法、2026年施行）の適用有無
- 紹介パートナー契約（紹介料20%）の書式

## 依頼方法

- 契約書ドラフトと本論点表を添えて、IT・事業法務を扱う弁護士2〜3名にスポット見積を依頼（予算15〜30万円【仮説】）
- 必要書類：利用規約、成功報酬契約書、秘密保持契約、プライバシーポリシー、紹介パートナー契約
