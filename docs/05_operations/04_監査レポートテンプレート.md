# {会社名} 様　配送費・物流請求 監査レポート

- 版数：v{n}　発行日：{YYYY-MM-DD}　担当：{氏名}
- 対象期間：{開始}〜{終了}（{n}か月）
- 対象データ：出荷実績CSV（{件数}件）、契約料金表（{運送会社}、{日付}版）、3PL請求書（{n}か月分）

## 1. サマリー

| 区分 | 内容 |
|---|---|
| 対象期間の配送費・物流費 | {金額}円 |
| 確定した過請求額（期間中） | **{金額}円** — 請求データ上の不整合。運送会社・3PLへの照会でご確認いただけます |
| 改善余地（月額・確認前） | {金額}円/月 |
| 推奨する施策数 | {n}件（うち実行容易 {n}件） |

## 2. 確定事項（請求データの不整合）

| # | 内容 | 件数 | 金額 | 根拠 |
|---|---|---:|---:|---|
| 1 | 重複請求 | | | 別紙明細 1 |
| 2 | 契約単価超過 | | | 別紙明細 2、料金表 p.{n} |

**ご対応のお願い**：上記は貴社から {運送会社/3PL} へ照会・確認をお願いします。照会用の明細（CSV）を添付しています。当社は照会・請求の代理は行いません。

## 3. 改善施策

| # | 施策 | 月間削減見込み | 算定式 | 確度 | 実行の手間 | 業務・品質への影響 | 制約（違約金等） |
|---|---|---:|---|---|---|---|---|
| 1 | 薄型商品の小型配送サービス化 | | 対象{n}件×単価差{円} | 推定 | 低 | ポスト投函（手渡しなし・補償額の上限に注意） | なし |
| 2 | サイズ区分の是正（梱包資材の変更） | | | 要確認 | 中 | 梱包作業の変更 | 資材の在庫 |
| 3 | 運賃単価の相見積 | | 現単価−見積単価 × 区分別数量 | 推定 | 中 | 運送会社の変更時は集荷時間・品質 | 契約期間 |

## 4. 実行しない方がよい施策（検討したが推奨しない）

| 施策 | 理由 |
|---|---|
| {例：最安運送会社への全面切替} | {例：遠隔地の配送日数が1日延び、レビュー評価への影響が削減額を上回るおそれ} |

## 5. 成功報酬の算定（ご参考）

- 算定方式：単価差 × 実数量 × 12か月 × 25%（税別）
- 例：施策1が実行され、検証月に対象{n}件・単価差{円}の場合 → 月間削減{円} → 報酬{円}
- 削減が実現しなかった施策には報酬は発生しません

## 6. 前提・留意事項

- 本レポートは提出データに基づく分析であり、削減額を保証するものではありません
- 「確定」は請求データ上の不整合、「要確認」は実物・計測記録での確認が必要、「推定」は条件変更・切替を前提とした見込みです
- 契約変更・切替の判断と実行は貴社が行うものとします
- 税務・会計上の扱いは貴社の税理士にご確認ください
