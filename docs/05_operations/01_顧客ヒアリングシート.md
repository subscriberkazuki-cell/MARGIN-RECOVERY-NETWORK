# EC事業者10社ヒアリング キット（v0.2：2026-11-10 経営判断を反映）

**目的は仮説検証。営業はしない。** 請求書・契約書・出荷CSVは受け取らない（提出の可能性だけを聞く）。
「配送費を5〜15%削減できます」等、削減率を先に伝えない。相手が自発的に挙げる問題・支出規模・障壁を聞く。

## 1. サンプル設計（10社）

| 枠 | 社数 | 見たい課題 |
|---|---:|---|
| A：宅配便中心・自社出荷型 | 4 | キャリア別の単価差、サイズ区分、重複請求、配送量の偏り |
| B：3PL・発送代行中心型 | 3 | 保管・作業・資材・出荷費の請求内訳、契約単価との照合可能性 |
| C：複数キャリア・自社と3PL併用型 | 3 | 契約・請求データの分散、比較・監査の運用負荷 |

検証用の割り振りであり市場構成比ではない。業種（美容・アパレル・日用品・食品など）は偏らないようにするが固定しない。
候補リスト30〜40社：`kpi/hearing_candidates.csv`。連絡経路は紹介・業界ネットワーク・知人を優先し、公開アドレスへの依頼は `docs/04_sales/02_営業メールテンプレート.md` の H1（送信前チェック必須）。

## 2. 30分の進行

| 時間 | パート | 主な質問 |
|---|---|---|
| 0〜5分 | 現状把握 | 月間出荷数（繁忙期・閑散期の差）、出荷拠点、利用キャリア、3PLの利用状況 |
| 5〜12分 | 費用構造 | 配送費・物流費の管理方法、契約単価・請求明細の保管方法、直近の値上げや追加料金 |
| 12〜19分 | 監査実態 | 請求の照合頻度・担当・所要時間、過去の誤請求や削減事例、照合しない理由 |
| 19〜25分 | 導入障壁 | データ抽出の難しさ、社内決裁者、取引先との関係、外部に情報を出す条件 |
| 25〜30分 | 価値・支払意思 | どの成果物なら価値があるか、成功報酬と月額監視のどちらが受け入れやすいか |

冒頭で伝えること：「配送費の管理実態を調べています。売り込みはしません。社名は出さず、集計した結果だけを今後のサービス設計に使います。資料のご提出は不要です。」

## 4. 面談後の判定（各社）

| 判定 | 基準 |
|---|---|
| 課題が具体的に存在 | 不満・不透明な項目を具体名で挙げ、金額や頻度に言及した |
| データ提供の可能性 | CSV出力が「可能」または「たぶん可能」 |
| 改善実行の意思 | 運送会社・3PLと自社で話す担当者がいる |
| 支払意思 | 成功報酬または月額のいずれかに前向きな反応 |

## 5. 10社完了時の合格基準

| 指標 | 基準 | 未達時 |
|---|---:|---|
| ヒアリング完了 | 10社 | 候補リスト・紹介経路を改善 |
| 課題が具体的に存在 | 6社以上 | 市場・課題設定を見直す |
| 診断用データを提供できる可能性 | 3社以上 | データ入手方法・商品設計を再検討 |
| 無料診断への具体的な関心 | 3社以上 | **合同会社化トリガーの1つ**（`docs/06_plan/03_個人事業開始と法人化判定.md`） |
