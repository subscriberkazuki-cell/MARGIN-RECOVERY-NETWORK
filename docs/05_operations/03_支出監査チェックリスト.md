# 支出監査チェックリスト（EC配送・3PL・決済）

各項目に「自動」＝`tools/audit` で機械判定可、「手動」＝人が確認、を付記。
**指摘は必ず根拠（追跡番号・請求行・契約条項）と紐付ける。根拠がない指摘は顧客に出さない。**

## A. 宅配運賃

| # | チェック項目 | 判定 | 必要データ | 確度 |
|---|---|---|---|---|
| A1 | 同一追跡番号の重複請求 | 自動 | 出荷CSV | 確定 |
| A2 | 契約単価（サイズ×地域）を超える請求 | 自動 | 出荷CSV＋料金表 | 確定 |
| A3 | 実寸・重量より大きいサイズ区分での請求 | 自動（寸法データがある場合） | 出荷CSV（3辺・重量） | 要確認（実物・計測記録で確認） |
| A4 | 小型・薄型配送サービスで送れる商品の通常便発送 | 自動 | 出荷CSV（3辺・重量） | 推定 |
| A5 | 梱包資材が商品に対して大きすぎ、サイズ区分が1つ上がっている | 手動（商品別の梱包寸法表） | 商品マスタ | 推定 |
| A6 | 地域別単価：遠隔地（北海道・沖縄・離島）の比率と単価 | 自動（集計） | 出荷CSV | 参考 |
| A7 | 着払い・再配達・返品の運賃負担の取り決めと実請求 | 手動 | 契約書・請求書 | 要確認 |
| A8 | 契約単価の最終改定日と出荷量の変化（交渉余地） | 手動 | 契約書・出荷推移 | 推定 |
| A9 | 複数運送会社の使い分け（サイズ・地域ごとの最安） | 自動（料金表が複数ある場合） | 複数社の料金表 | 推定 |
| A10 | 集荷代理店・カート付帯配送サービス経由の単価比較 | 手動 | 見積 | 推定 |

## B. 3PL・発送代行（第2段階：標準監査の範囲外。ヒアリングでニーズ確認のみ）

| # | チェック項目 | 判定 | 確度 |
|---|---|---|---|
| B1 | 保管料：在庫ゼロSKU・終売品への課金 | 手動→Phase 4で自動 | 確定/要確認 |
| B2 | 保管料の計算単位（坪・パレット・棚・才）と実在庫の整合 | 手動 | 要確認 |
| B3 | 入庫料・検品料：入荷数と請求数の一致 | 手動→自動 | 確定 |
| B4 | ピッキング・梱包料：出荷数・同梱数と請求数の一致 | 手動→自動 | 確定 |
| B5 | 資材費：実使用量との整合 | 手動 | 要確認 |
| B6 | 配送料の上乗せ（3PL経由の運賃と直接契約の比較） | 手動 | 推定 |
| B7 | 長期保管在庫の処分・移管による保管料削減 | 手動 | 推定（顧客の在庫方針次第） |
| B8 | 最低保証料金・最低利用期間・解約予告期間 | 手動 | 参考（切替の制約） |
| B9 | SLA（誤出荷率・出荷リードタイム）未達時の取り決め | 手動 | 参考 |

## C. 決済手数料（第2段階：標準監査の範囲外）

| # | チェック項目 | 判定 | 確度 |
|---|---|---|---|
| C1 | ブランド別料率と契約料率の一致 | 手動 | 確定 |
| C2 | 料率の税込/税抜/非課税の区別 | 手動 | 確定 |
| C3 | 月額固定費・入金手数料・振込手数料 | 手動 | 確定 |
| C4 | 決済額規模に対して料率の見直し余地（他社比較） | 手動 | 推定 |
| C5 | 使っていない決済手段の月額費用 | 手動 | 確定 |

## D. 施策評価（提案前に必須）

| # | 項目 |
|---|---|
| D1 | 解約違約金・最低利用期間・切替費用を差し引いた正味削減額 |
| D2 | 配送品質（遅延・破損・追跡・補償額）への影響 |
| D3 | 顧客体験（お届け日数・ポスト投函の可否）への影響 |
| D4 | 社内オペレーション（梱包・出荷作業）の変更負担 |
| D5 | 税務・会計上の扱い（返金の計上等）→ 顧客の税理士へ |
| D6 | 当社の関与範囲（交渉・請求の代理になっていないか） |
