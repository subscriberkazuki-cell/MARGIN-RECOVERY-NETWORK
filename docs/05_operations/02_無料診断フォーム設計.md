# 無料診断フォーム設計

実装：LP（`site/index.html`）の診断セクション → Googleフォーム（Phase 2）。顧客のファイルはフォームでは受け取らず、申込後に顧客別の共有フォルダを発行する（ファイルの取り違え・誤共有を防ぐため）。

## 1. 入力項目

| # | 項目 | 形式 | 必須 | 目的 |
|---|---|---|:---:|---|
| 1 | 会社名 | テキスト | ○ | |
| 2 | ご担当者名 | テキスト | ○ | |
| 3 | 役職 | 選択（代表／EC責任者／物流担当／経理／その他） | ○ | 意思決定者判定 |
| 4 | メールアドレス | メール | ○ | 連絡（同意記録として保存） |

## 2. 同意事項（チェックボックス）

- [ ] プライバシーポリシーに同意します
- [ ] 提出データからお届け先の氏名・住所・電話番号を削除して提出します（削除方法のご案内あり）
- [ ] 無料診断の結果は提出データに基づく機械照合結果であり、削減を保証するものではないことを理解しました
- [ ] MARGIN RECOVERY NETWORK からサービスに関するメールを受け取ることに同意します（任意）

## 3. 申込後の自動処理

| 条件 | 処理 |
|---|---|
| 月間出荷1,000件以上 | 顧客別共有フォルダを作成し、提出案内メール（下書き → 承認 → 送信） |
| 月間出荷500〜1,000件 | 同上（ただし本監査ではなく WATCH Lite を案内候補に） |
| 月間出荷500件未満 | 無料チェックリスト（自己点検版）を送付し、人手診断はしない |

## 4. 提出案内に含める内容

1. 必要ファイル：出荷実績CSV（直近1か月）、運送会社の契約料金表（PDF可）、3PL利用時は請求書1か月分と料金表
2. 削除してほしい列：お届け先氏名・住所（都道府県は残す）・電話番号・メールアドレス
3. 残してほしい列：追跡番号、出荷日、運送会社、サービス名、サイズ、重量、（あれば）3辺寸法、届け先都道府県、運賃
4. 提出期限の目安：5営業日
5. 結果説明の日程調整リンク
