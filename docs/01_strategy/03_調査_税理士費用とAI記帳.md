# 調査：サロンの税理士費用は、記帳をAIに任せると下げられるか

調査日：2026-11-10 ／ 【事実】出典あり（多くは第三者サイト・解説記事）・【判断】当社の意思決定

## 結論

1. **仮説は正しい。** 個人サロンが税理士に払う費用の多くは「記帳（レシート・帳簿の入力）」と「確定申告」の手間への対価。記帳を自分で（アプリで）行えば、税理士への支払いは下げられる可能性が高い
2. **ただし、当社が会計アプリを作るのはやめる。** freee・マネーフォワード・弥生が、口座・カードの自動連携、レシートの写真読取、確定申告書の作成・電子申告までを**年1〜2万円台**で提供済み。1〜2名で対抗できない。さらに税理士法の制約と、記帳ミスの責任リスクがある
3. **代わりに「税理士・記帳の費用」を固定費チェックの6番目の項目に入れた（実装済み）。** 記帳込みで税理士に払っている店に対し、「会計アプリで自分で記帳＋税理士には申告だけ依頼」した場合の費用差を、相場から計算して示す。サロン1店の見直し余地のなかで最大の項目になり得る

## 1. 税理士費用の相場（個人事業主）

| 依頼の範囲 | 年間の目安 | 出典 |
|---|---:|---|
| 確定申告のみ（白色） | 5〜10万円 | 税理士ドットコム 解説 |
| 確定申告のみ（青色・売上1,000万円未満） | 7〜15万円 | 同上 |
| 確定申告のみ（青色・売上3,000万円未満） | 10〜20万円 | 同上 |
| 記帳から申告まで丸投げ | 10〜25万円 | 行政書士サイトの解説 |
| 個人事業主全般 | 5〜30万円 | 解説サイト |

いずれも紹介サイト・広告を含むメディアの数字で、地域・取引件数・事務所により大きく変わる。

→ 「レシートを撮るだけ」「入力も任せる」は、すでに大手が低価格で商品化している。

## 3. 法令上の制約

| 論点 | 内容 | 出典 |
|---|---|---|
| 税理士の独占業務 | 税務代理・税務書類の作成・税務相談は、**有償・無償を問わず**税理士以外が行えない（税理士法52条、罰則59条） | 解説記事（士業） |
| 記帳代行 | 仕訳入力・帳簿作成は原則として独占業務に含まれない | 税理士ドットコム（税理士の回答） |
| グレーゾーン | 「この支出は経費になるか」など税務上の解釈を伴う判断は52条に抵触するおそれ | 同上 |
| AIによる申告書作成 | 無資格者がAIで申告書作成を代行するのは違法との見方（事務所ブログの見解で、確定判断ではない） | 解説記事 |
| 電子帳簿保存法 | 2024年1月から、メール・Webで受け取った請求書・領収書は原則として電子データのまま保存。2027年1月から青色申告の上乗せ控除に関わる新ルールの予定 | 解説記事（猶予措置の要件は未確認。国税庁で要確認） |

→ 当社が「AIで経費判断・申告書作成」をするアプリを作ると、税理士法のリスクを負う。会計アプリ大手は「本人が使う道具」として提供している。

## 4. 「自社アプリ」案を却下した理由

| 理由 | 内容 |
|---|---|
| 競合 | 大手3社が年1〜2万円台で、自動連携・撮影読取・申告・電子申告まで提供。入力代行まである |
| 法令 | 経費の判断や申告書作成に踏み込むと税理士法52条のリスク |
| 責任 | 記帳ミスは追徴課税につながる。美容室は税務調査の対象になりやすいとの指摘もある（解説記事） |
| 資金・人手 | 会計アプリの開発・保守・法改正対応は、1〜2名・100万円以内では不可能 |
| 弁護士費用 | 自社の弁護士費用（契約書のレビュー）は、記帳の自動化では下がらない。当社自身の会計は、個人事業として上記のアプリを使えば足りる |

## 5. 採用した方針

### 5-1. 固定費チェックに「税理士・記帳」を追加（実装済み）

- 入力：税理士への年間支払い、記帳も任せているか、従業員がいるか
- 判定（`tools/salon/fixed_cost_check.py`、`tools/salon/check.html`）

| 状況 | 判定 |
|---|---|
| 記帳込みで、会計アプリ＋申告のみの目安を上回る | **推定**：差額を月額で表示（下限＝相場の上限との差、上限＝相場の下限との差） |
| 申告のみで相場の上限を超える | 要確認（金額は出さない） |
| 年商3,000万円以上 | 要確認（相場データがないため金額は出さない） |
| 目安以下 | 問題なしとしてメモのみ |

- 例：年商960万円・記帳込みで年24万円 → 月5,500〜13,300円（年6.6〜16万円）の見直し余地
- 必ず添える注意：記帳を自分でする時間と正確さの負担、税理士が必要なケース（売上規模・消費税・従業員・税務調査）、**当方は税務相談をしない**

### 5-2. 紹介元の方針を変更

- 税理士費用の見直しを提案する以上、**今の顧問税理士に紹介を頼むのは利益相反**になる。紹介元の主軸は「サロンオーナー同士の紹介」と、美容ディーラー・開業支援・予約/POS事業者などに切り替える
- 「記帳はアプリ、税理士は申告とチェックだけ」という形を歓迎する**クラウド会計に強い低価格の税理士**とは協力できる可能性がある。ただし当社は紹介料を受け取らない（中立性を保ち、税理士側の規程の問題も避ける）

### 5-3. 将来の選択肢（今はやらない）

- 会計アプリの導入・初期設定の手伝い（口座・カードの連携、レシート撮影の習慣化）。**経費になるかの判断や申告の助言はしない**範囲で、需要があれば有料オプションとして検証する
