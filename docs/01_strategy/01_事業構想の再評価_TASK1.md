# TASK 1：事業構想の再評価

作成日：2026-11-09 ／ 区分表記：【事実】出典あり・【仮説】未検証の推定・【判断】当社の意思決定

---

## 0. 結論（先に読む）

1. **事業は「条件付きで有望」。ただし当初構想のままでは採算が合わない。**
   「中小企業・個人事業主の何でも経費削減」を成功報酬で請け負う形は、1社あたり削減額が小さく、営業・資料回収・効果検証の手間が報酬を上回る。
2. **初期市場は美容室ではなく、年商1〜10億円のEC事業者に変更する。**
   監査対象は「配送費（宅配運賃・サイズ区分）」と「3PL請求」と「決済手数料」の3つに絞る。
   美容室を初期市場にすると、月利益50万円に月12件前後の削減実現が必要になり、1〜2名では回らない（`finance/simulate.py` 参照）。
3. **初期商品は「EC配送費監査（成功報酬25%×12か月・単価差方式）」1本。**
   無料診断は「出荷CSV1か月分のアップロード → 自動突合」に限定し、無料作業を最小化する。
4. **美容室は捨てない。** POS・予約システム代理店経由の低単価・大量処理商品として Phase 6 で再検討する（直接営業はしない）。
5. **最大のリスクは法務（弁護士法72条・特定電子メール法）と、成功報酬の算定トラブル。** 事業開始前に弁護士レビューを必須とする（予算15〜30万円・見積要）。
6. **撤退・転換基準を先に決める。** 営業開始60日で「削減余地5%以上を発見できた診断」が3件未満なら、監査対象または市場を変更する。

## 1. 当初構想の強みと弱み（忖度なし）

| 観点 | 評価 | 根拠 |
|---|---|---|
| 顧客の課題の実在性 | ◎ | 配送運賃は年度ごとの値上げが続いている【事実】。ヤマト運輸は2023年4月に約10%値上げ後、年度ごとに改定する方針を示し、2025年10月に120〜200サイズを平均3.5%値上げ（STOCKCREW解説記事、2026年確認）。2026年度は標準的運賃引上げ・改正物流効率化法・取適法の施行が重なる |
| 成功報酬の受け入れやすさ | ○ | 顧客の持ち出しがないため初回の心理的障壁は低い。ただし「削減額の定義」で揉めやすい |
| 1社あたり報酬 | △〜× | 美容室：削減額 月1〜3万円【仮説】→報酬 3〜9万円。EC（月間出荷1,000件以上）：月5〜15万円【仮説】→報酬15〜45万円 |
| 競争優位 | △ | 「AIで請求書を読む」こと自体は差別化にならない（会計SaaS・SaaS管理ツールが無料〜低価格で提供）。**優位性は①垂直特化の料金ベンチマークデータ、②ベンダー中立、③根拠付きの成果算定**から作るしかない |
| 自動化可能性 | ○ | 配送・3PL請求はCSVで取得でき、ルールで機械突合できる（本リポジトリ `tools/audit/` で実装済み）。紙の請求書・契約書が中心の店舗系は手作業が残る |
| 法務リスク | × | 第三者との交渉・返金請求を報酬目的で代行すると弁護士法72条（非弁行為）に抵触するおそれ。債務整理交渉を非弁護士が回収額の30%で行った事例が違法とされた裁判例あり（東京地判平成21年4月13日、解説記事より）【事実】。**当社は「分析・提案・見積取得の支援」に限定し、交渉・請求の代理はしない設計にする**【判断】 |
| 営業規制 | △ | 特定電子メール法はオプトイン原則。法人・営業個人が自ら公表したアドレスは例外だが、「広告メールお断り」の表示がある場合は送信不可、同意取得時は記録保存義務あり（総務省パンフレット）【事実】 |

### 構想の修正点

| 当初構想 | 修正後 | 理由 |
|---|---|---|
| 多数の支出領域を網羅 | 3領域に限定（配送費・3PL・決済手数料） | 1領域ずつルール化しないと自動化できない |
| 過払い「回収」も成功報酬対象 | 回収は「顧客自身による請求の支援資料作成」に限定。請求代行はしない | 非弁リスク |
| 美容室が初期市場 | EC事業者が初期市場 | 1社あたり報酬が約4倍、データがCSVで揃う |
| MARGIN WATCH 3,980円〜 | EC向けは19,800円/月を基本 | 3,980円では月利益50万円に約125社以上必要（固定費除く）。EC向けは月次の運賃・3PL請求チェックの価値に見合う |
| ExpleeでAI営業 | 送信可否判定を自社で行い、Expleeは小額検証のみ | 日本語精度・送信元・配信停止管理・データ取得元が未確認 |
| 多エージェントを最初から構築 | 最初の10社は手動＋スクリプト。自動化は再現性を確認した工程から | 経営条件「手動・半自動から」 |

### 選定結果

- **第1市場：EC事業者（年商1〜10億円、月間出荷1,000〜20,000件、自社出荷または3PL委託）**
- **第2市場（Phase 6で検証）：多店舗サービス業（5〜30店舗の飲食・サロン・クリニック）** — 電気・通信・決済・複合機を店舗数分まとめて見直せるため1社あたり削減額が大きい。ただし意思決定者に届きにくく営業期間が長い
- **入口のみ：EC（年商1億円未満）** — 67点で2位だが最重要の「1社あたり削減額」が低い。人手ゼロの自動診断の入口としてのみ受け入れ、本監査は月間出荷1,000件以上に限定（第4節）
- **却下：美容室・ネイル・小規模飲食・士業への直接営業** — 1社あたり報酬が小さすぎる。POS代理店・会計事務所経由で「自動診断のみ」の低価格商品を出す場合に限り再検討

## 4. 年商1億円未満のECを外す理由

月間出荷が数百件では配送費自体が月30万円未満で、削減しても報酬が数万円にとどまる。運送会社の契約割引も出荷量に依存するため交渉余地が小さい。ただし無料診断の自動化が完成すれば「自動診断のみ・人手ゼロ」の入口として受け入れる（その場合も本監査は月間出荷1,000件以上に限定）。

| 6か月 | 月間営業利益20万円以上 | 事業継続を再審議 |
