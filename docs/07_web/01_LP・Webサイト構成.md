# LP・Webサイト構成

実装：`site/index.html`（静的HTML・外部依存はGoogle Fontsのみ）。ホスティングは Cloudflare Pages（無料枠・商用可）を想定。

## 1. ブランド

| 要素 | 方針 |
|---|---|
| トーン | 信頼・精密・透明。安売りの「コスト削減業者」に見せない。煽り表現（「必ず」「驚きの」）禁止 |
| 色 | ネイビー（#14213d）× アイボリー（#f7f5f0）× ゴールド（#9a7b3f）。ダークモード対応 |
| 書体 | 見出し：Noto Serif JP／本文：Noto Sans JP |
| メッセージ | 「配送費の請求、契約どおりですか。」— 問いかけで、顧客が自社の状態を確認したくなる形 |
| 3つの約束 | 根拠付き／成功報酬のみ／ベンダー中立 |

## 2. ページ構成（MVP：1ページ＋法務ページ）

| # | 要件のページ | 実装場所 | 状態 |
|---|---|---|---|
| 1 | トップページ | `site/index.html` ヒーロー | ✅ |
| 2 | サービスの仕組み | `#how` | ✅ |
| 3 | 監査対象の支出 | `#targets` | ✅ |
| 4 | 成功報酬の仕組み | `#fee`（算定式・架空のモデルケース） | ✅ |
| 5 | MARGIN WATCH | `#watch` | ✅ |
| 6 | 導入事例 | `#cases`（実績なしと明記。架空事例は掲載しない） | ✅ |
| 7 | 無料診断 | `#diagnosis`（Googleフォームへ。URL未設定時はリンク無効） | ⏳ フォームURL待ち |
| 8 | よくある質問 | `#faq` | ✅ |
| 9 | 会社情報 | `#company` | ⏳ 事業形態決定後に記入 |
| 10 | プライバシーポリシー | 別ページ | ⏳ 弁護士レビュー後 |
| 11 | 利用規約 | 別ページ | ⏳ 弁護士レビュー後 |
| 12 | お問い合わせ | 診断フォームと共用 | ⏳ |

実績が出るまでは1ページで十分。SEO記事を書き始めたら `/articles/` を追加する。

## 3. 公開前チェックリスト

- [ ] 会社情報（名称・所在地・連絡先）を記入
- [ ] Googleフォームを作成し `data-form-url` を差し替え
- [ ] プライバシーポリシー・利用規約を公開しフッターのリンクを更新
- [ ] 「完全成果報酬」「削減額」の表示が景品表示法上問題ないか最終確認（実績値を出していないこと）
- [ ] OGP画像・favicon
- [ ] アクセス解析（Cloudflare Web Analytics：Cookie不要）

## 4. 公開手順（Cloudflare Pages）

1. Cloudflare アカウントを作成し、このリポジトリを接続
2. ビルドコマンド：なし／公開ディレクトリ：`site`
3. 独自ドメインを接続（DNSを Cloudflare に移管）
4. 公開後、スマートフォンで表示確認
