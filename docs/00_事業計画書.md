# MARGIN RECOVERY NETWORK 事業計画書 v0.1

作成日：2026-11-09 ／ 状態：仮説段階（顧客ヒアリング前）

## 1. 事業の一文定義

**年商1〜10億円のEC事業者の配送費・物流請求を、出荷データと契約料金表で機械照合し、払いすぎを根拠付きで特定して、削減できた分だけ報酬を受け取る中立の監査サービス。**

当初構想（中小企業・個人事業主の経費全般／美容室起点）から、初期市場と監査対象を絞り込んだ。理由は `01_strategy/01_事業構想の再評価_TASK1.md`。

## 2. 顧客と課題

| 項目 | 内容 |
|---|---|
| 顧客 | 年商1〜10億円、月間出荷1,000〜20,000件のEC事業者 |
| 課題 | 宅配運賃が年度ごとに改定される中、毎月数千件の請求を契約料金表と照合する時間がない。サイズ区分・サービス選択の最適化も後回し |
| きっかけ | 運送会社・3PLからの値上げ通知（毎年発生） |
| 既存の選択肢の不満 | 3PL・発送代行の無料見積は乗換が目的で中立ではない。物流コンサルは中小には高い |

## 3. 提供価値と商品

| 段階 | 商品 | 価格 |
|---|---|---|
| 入口 | 無料診断（出荷CSV1か月分の自動照合） | 0円 |
| 主力 | MARGIN AUDIT for EC（配送・3PL・決済手数料の監査） | 実現削減額×12か月×25% |
| 継続 | MARGIN WATCH（月次照合・運賃改定の監視） | 3,980／19,800／49,800円/月 |

## 4. 競争優位

1. ベンダー中立（紹介手数料を受け取らない）
2. 根拠付きの算定（確定／要確認／推定の区別、すべて請求行に紐付け）
3. 小口でも採算が合う自動照合（`tools/audit`）
4. 長期：顧客同意のもと蓄積する、出荷量帯別の運賃単価ベンチマーク（唯一の参入障壁）

## 5. 収益計画（`06_plan/02_収益シミュレーション結果.md`）

| シナリオ | 月間削減実現 | 1社あたり報酬 | 12か月目の営業利益 | 月利益50万円到達 |
|---|---:|---:|---:|---|
| 悲観 | 0.5件 | 15万円 | 約-1万円 | 未達 → 撤退・転換基準で判断 |
| 標準 | 2.9件 | 24万円 | 約68万円 | 8か月目 |
| 楽観 | 6.6件 | 36万円 | 約249万円 | 5か月目 |

**月利益50万円の条件（WATCH収益を除いた保守的な計算）**：1社あたり月間削減8万円なら、毎月2.8件の削減実現が必要。月5万円なら4.5件。

## 6. 組織・運営

- 創業者1名＋AIエージェント7役割（`03_system/02_AIエージェント組織とシステム構成.md`）
- 数値は決定論的プログラム、LLMは抽出・分類・文章化のみ
- 送信・金額提示・請求はすべて人間承認。契約・解約・支払いは顧客本人のみ

## 7. 資金計画

- 初期投資：約58〜80万円（弁護士レビュー・保険・ツール・予備費。上限100万円以内）
- 月間固定費：実費 約3,000〜25,000円（シミュレーションは保守的に9万円/月で計上）
- 標準シナリオの累積損益は6か月目にプラス転換

## 8. 主要リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 弁護士法72条（非弁行為） | 事業停止 | 交渉・請求代理をしない業務設計。開始前に弁護士レビュー |
| 特定電子メール法違反 | 行政処分・信用失墜 | 公表アドレス・拒否表示なしのみ送信、取得元と判定の記録、即日配信停止 |
| 削減余地が仮説より小さい | 収益未達 | 最初の10社ヒアリングで検証。60日の撤退・転換基準 |
| 成功報酬の算定トラブル・未回収 | キャッシュ不足 | 単価差×実数量の算定式、顧客の書面承認、2回払い、未回収5%を計画に織り込み |
| 誤った指摘による信用毀損 | 解約・評判 | 「確定」は機械照合のみ、抜き取り検証、確定指摘の誤り率0%を品質基準に |
| 顧客データの漏えい | 損害賠償 | 個人情報を受け取らない運用、顧客別に分離、90日で削除、賠償責任保険 |
| 運送会社の値上げで削減が相殺 | 成果の見え方 | 「値上げがなかった場合の単価」ではなく「変更前の契約単価」との差で算定し、値上げ対応の価値は別途レポートで説明 |
