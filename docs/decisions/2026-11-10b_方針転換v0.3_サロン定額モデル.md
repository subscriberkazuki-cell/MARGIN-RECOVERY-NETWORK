# 方針転換 v0.3：サロン向け「定額・半自動の固定費チェック」から始める

日付：2026-11-10 ／ 決定者：事業責任者（方針は Claude の推奨を採用）／ 状態：**4週間の検証つきで採用**

## 1. 結論

| 論点 | v0.2（EC配送費・成功報酬） | **v0.3（採用）** |
|---|---|---|
| 最初の市場 | 年商1〜10億円のEC事業者 | **小規模サロン（美容室・ネイル・エステ・まつげ、1〜5店舗）** |
| 商品の形 | 成功報酬の監査コンサル（実請求への反映分×25%、最大12か月） | **定額の固定費・集客費チェック（19,800円・返金保証つき）＋月額の見直し通知（2,980円）** |
| 誰が見直すか | 顧客（当社は交渉しない） | 顧客（同じ） |
| データ | 請求明細CSV・契約運賃表を受領 | **5分の質問票の数値だけ。書類は原則受け取らない** |
| 販路 | 直接メール＋紹介 | **サロン専門の税理士・会計事務所などの紹介元を主軸** |
| 必要資金 | 約60〜110万円 | **約10〜25万円**（試算） |
| 月利益50万円（標準） | 16か月目 | 月20件では18か月以内に未達。**月30件程度の診断が必要** |
| EC配送費 | 主力 | **Phase 2（成熟後）**。エンジン・資料は保持 |

## 2. 理由

### 事業責任者の指摘は正しい
- 配送の実務ノウハウがない状態で、EC事業者の物流担当者を相手に1社ずつ監査するのは、見通しが立てにくい
- 手作業が多く、必要資金が上限を超えるおそれがあり、黒字化に時間がかかる

### 本当の問題は「市場」より「商品の形」だった（Claude の設計の反省）
- 成功報酬の監査コンサルは、①実データの受領 ②1件ずつの手作業 ③反映確認と月次請求 ④成果の帰属をめぐる紛争リスク（弁護士法72条を含む）を必ず伴う。手作業・資金・法務の負担はこの形から生じていた
- 定額の診断（顧客が自分で見直す。当社は交渉も成果連動の報酬も扱わない）にすれば、4つとも大きく減る

### ただし「美容室に成功報酬で経費削減」はやらない
- 1店あたりの見直し余地は月1〜3万円程度（仮説。架空サンプルの試算でも月1.1〜3.4万円）。成功報酬25%×12か月だと1店約6万円で、月利益50万円には毎月12件の削減実現が必要（v0.1 試算）
- 電力・決済・通信の販売代理店が「無料の見直し」を提供している（販売先からの手数料で収益化）。成功報酬で1店ずつ争う意味が薄い

### 定額・半自動なら「入り込む余地」がある
- サロンの請求項目（決済・予約/POS・通信・電気・集客媒体）は店ごとの差が小さく、質問票と決まった計算で判定できる → 半自動化しやすく、物流のような専門ノウハウがいらない
- 美容業は人件費が売上の約45%、諸経費が約37.5%（日本政策金融公庫 2024年調査、弥生の解説より）。オーナーが自分で動かせる費目は限られる。だからこそ「どこを見ればいいか」を短時間で示す価値がある
- サロン専門の税理士事務所が実在する（比較サイトに14〜27事務所掲載）。顧問先に配る付加価値として紹介元になり得る
- 代理店の無料見直しとの違い：**販売手数料を受け取らない中立の診断**。乗換先を売らず、解約・プラン変更・重複整理など「契約を減らす」提案もする（代理店は収益にならないためやらない）

## 3. 正直なリスク

| リスク | 内容 | 検証方法 |
|---|---|---|
| 支払意思 | 月1〜3万円の見直しに、19,800円を払うかは未検証。代理店の無料見直しと比べられる | ヒアリングで価格への反応、テスト販売 |
| 規模の天井 | 月利益50万円には月30件程度の診断が必要。直接営業だけでは届かない可能性が高い | 紹介元が1社あたり月何件紹介できるか |
| 優先度 | サロンオーナーの最大の悩みは集客と人材（倒産原因の83%が販売不振） | ヒアリングで固定費見直しの優先順位を聞く。集客費の費用対効果を診断に入れたのはこのため |
| 月額の価値 | 固定費は毎月変わらないので、月額2,980円の継続価値が弱い | 診断後に継続希望を聞く。弱ければ月額を作らず「年1回の再診断」にする |
| 情報の鮮度 | 決済料率などの比較基準が古くなる | `tools/salon/benchmarks.json` に確認日を持たせ、月1回更新 |

## 4. 4週間の検証（追加投資10万円以内）

計画：`docs/06_plan/05_サロン検証4週間計画.md`

| 合格基準（4週目） | 基準 |
|---|---:|
| サロンオーナーのヒアリング | 10店 |
| 「直近2年以上見直していない固定費がある」 | 5店以上 |
| 19,800円（返金保証つき）での申込・申込意思 | 3店以上 |
| テスト診断で年間見直し余地が診断料を超えた店 | 3店中2店以上 |
| 1診断の人手時間 | 60分以内 |
| サロン専門の税理士・紹介元のテスト協力 | 1者以上 |

- **全部を満たす** → サロン定額モデルで本格化（利用規約・プライバシーポリシーを整え、紹介元を5者に広げる）
- **支払意思はあるが紹介元が0** → 直接営業の上限を見極めつつ、多店舗（3〜10店）サロンに対象を寄せる
- **支払意思が3店未満** → 撤退または別市場を検討（この時点の損失は10万円以内）

## 5. v0.2 の資料の扱い

- EC配送費の監査エンジン・資料・弁護士見積依頼書は **Phase 2 の資産として保持**（削除しない）
- **弁護士への見積依頼（EC・成功報酬版）は送らない。** サロン定額モデルは交渉・成果連動の報酬がないため論点が小さい。検証合格後に、利用規約・プライバシーポリシー・紹介元契約の範囲で見積を取る（費用は見積要）
- 個人事業での開始（v0.2の決定）は変更なし。合同会社化は当面不要
