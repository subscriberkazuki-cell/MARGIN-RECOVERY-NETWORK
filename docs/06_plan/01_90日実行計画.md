## 60日目（W10）の判定

| 判定 | 条件 | アクション |
|---|---|---|
| 継続 | 無料診断3件以上、複数社で5%以上の削減可能性、顧客に改善実行の意思 | 有償パイロットへ。営業量を段階的に増やす |
| 商品転換 | 課題は強いが宅配便請求の削減余地が弱い | 3PL請求・決済手数料・その他物流関連費へ（各領域の監査ロジックと法務を別途検証） |
| 市場転換 | 課題はあるが年商1〜10億円層でデータを出せない・決裁が進まない | より大規模なEC事業者、または物流会社・EC支援会社経由に切替 |
| 撤退・一時停止 | 診断3件未満、重大な法務上の障害、データ取得不能、監査コストが報酬を上回る状態の継続 | 営業投資を止める |

診断件数だけでなく、データが揃っているか、監査工数、顧客が実際に料金改定を行えるかも併せて評価する。

## 資金計画の注意（重要）

成功報酬を月次後払い（最大12か月）にしたため、立ち上がりが遅くなった（`02_収益シミュレーション結果.md`）。

| | v0.1（一括算定） | v0.2（月次後払い・営業開始3か月目） |
|---|---|---|
| 月利益50万円の到達（標準） | 8か月目 | **16か月目** |
| 累積黒字化（標準） | 6か月目 | **12か月目** |
| 運転資金の最大不足（標準・固定費月6万円） | 約29万円 | **約56万円**（固定費を実費の月3万円にすると約35万円） |

初期費用（約25〜53万円）と合わせると、標準シナリオで必要資金は**約60〜110万円**となり、上限100万円を超える可能性がある。対策：
1. 固定費を実費（月3万円以下）に抑える
2. 弁護士費用は A（72条）と B（成功報酬）を優先し、範囲を絞って見積を取る
3. 合同会社の設立はトリガー条件を満たすまで行わない
4. 60日・90日判定で基準未達なら営業投資を止める（悲観シナリオの損失拡大を防ぐ）
5. 弁護士レビューで問題がなければ、算定期間中の報酬を四半期ごとの前払い精算にする等、受領を早める設計を相談する
