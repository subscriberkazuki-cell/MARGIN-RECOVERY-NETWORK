# 個人事業の開始と合同会社化の判定

決定（2026-11-10）：**個人事業で検証を開始する。** 顧客の実データを受け取る診断・有償契約の前に、合同会社化を再判定する。

## 1. 個人事業の開始チェックリスト（W1）

| # | 項目 | 期限・注意 | 状態 |
|---|---|---|---|
| 1 | 開業日を決める | 実際に事業を始めた日（例：ヒアリング開始日）。税理士と相談 | ☐ |
| 2 | 個人事業の開業・廃業等届出書を税務署へ | 開業日から1か月以内が目安 | ☐ |
| 3 | 所得税の青色申告承認申請書 | 1月16日以後の新規開業は、原則として開業日から2か月以内（国税庁）。開業日を基準に確認 | ☐ |
| 4 | 適格請求書発行事業者の登録 | 顧客は法人中心のため登録が望ましいか税理士に確認（消費税の負担とあわせて判断） | ☐ |
| 5 | 屋号を決める（例：MARGIN RECOVERY NETWORK） | 屋号付き口座を開く場合は銀行へ | ☐ |
| 6 | 事業用口座・事業用カード | 個人の支出と分離 | ☐ |
| 7 | 独自ドメイン取得、業務用メール（Google Workspace等） | 個人用メールと顧客情報を分離 | ☐ |
| 8 | パスワード管理ツール（Bitwarden等）＋全サービスで多要素認証 | 個人アカウントと事業アカウントを分離 | ☐ |
| 9 | 会計ソフト（freee または マネーフォワードのいずれか1つ） | 最初から複数契約しない | ☐ |
| 10 | 勤務先がある場合、副業規程の確認 | | ☐ |

## 2. ヒアリング段階のルール

- 聞くのは売上規模・月間出荷数・配送費の概算・利用キャリア・現状の照合方法などを**口頭で**
- 請求書・契約書・出荷CSVの提出は求めない（受け取らない）
- 録音する場合は事前に同意を得る

## 3. 合同会社化のトリガー（4条件すべてで設立を実行）

| # | 条件 | 判定時期 |
|---|---|---|
| 1 | 10社ヒアリングで、3社以上から実データでの無料診断への具体的な関心 | W3 |
| 2 | 弁護士レビューで、提供業務・成功報酬・契約書の重大な修正方針が確定 | W4〜6 |
| 3 | 顧客データの保管場所・アクセス権・再委託・削除・事故対応のルールが整う | W5〜6 |
| 4 | 最初の顧客データ受領・診断・有償契約の前に、契約主体と責任範囲を明確化 | W6 |

条件1が未達の場合は設立しない（60日判定まで個人事業のまま検証を続けるか、転換を検討）。

## 4. 設立時の確認事項

- 登録免許税：資本金額の0.7%（最低6万円）。合同会社は定款認証不要（法務省）
- 法人住民税均等割（本店所在地の自治体）
- 社会保険：法人は原則として適用事業所。役員報酬の有無・業務実態で扱いが変わるため、年金事務所または社会保険労務士に事前確認（無報酬役員のみの場合は要件を満たさないケースがある：日本年金機構）
- 既存勤務先がある場合の二以上事業所勤務の手続き
- 資本金、決算期、事業目的、代表社員、会社名、銀行口座
- 個人事業から法人への契約・ソフトウェア・ドメイン・知的財産・顧客情報の移転方法

**注意**：合同会社の有限責任は、代表者個人の故意・重過失、個人保証、法令違反まで無条件に遮断するものではない。法人化しても情報漏えい・監査ミスのリスクは消えない（保険・運用ルールで対処）。
