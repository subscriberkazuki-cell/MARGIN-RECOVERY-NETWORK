# 初回サロン（1店舗）実施ガイド

協力してくれる1店で、**商品が回るかを確かめる**ための手順。所要時間は約60分。

## 1. この1店で確かめられること／確かめられないこと

| 確かめられる | 確かめられない |
|---|---|
| 質問票にオーナーが答えられるか（分からない項目はどれか） | 一般のサロンが19,800円を払うか（知り合いの店は好意的に答えやすい） |
| 1件の診断にかかる時間（目標60分以内） | 市場全体での需要 |
| 実際の店で見直し余地がいくら出るか（診断料を超えるか） | 紹介元が動くか |
| 結果の説明がオーナーに伝わるか、行動につながるか | |

→ この店の「払う」は参考値として記録し、合格基準（3店以上）の判定は、この店から紹介してもらう2〜3店を含めて行う。

## 2. 事前準備（前日まで）

- [ ] `tools/salon/check.html` をPC（またはタブレット）にダウンロードし、ブラウザで開けることを確認。「架空サンプルを入れる」→「結果を出す」で動作確認
- [ ] オーナーに当日用意してもらうもの（見せてもらうだけ。預からない・撮影しない）：
  - 決済サービスの手数料が分かるもの（明細や管理画面）
  - 使っているツール・回線の月額が分かるもの（通帳・カード明細でも可）
  - 直近の電気の検針票（金額と使用量kWh）
  - 集客媒体の請求額と、その媒体からの新規客数（予約管理画面など）
- [ ] 伝えておくこと：「テストなので無料。資料はお預かりしません。結果はお店のものです」

## 3. 当日の進め方（約60分）

| 時間 | 内容 | ポイント |
|---|---|---|
| 0〜5分 | 趣旨の説明・同意 | 「サービスを作るためのテストです。お店の名前を出すことはありません。入力した数字はこのPCの中だけで計算し、どこにも送りません」 |
| 5〜20分 | ヒアリング（`05_サロン検証4週間計画.md` 第3節の質問） | 経営で一番困っていること、固定費の見直しは何番目か、無料見直しの営業を受けた経験 |
| 20〜40分 | 質問票を一緒に入力（`check.html`） | **分からなかった項目・時間がかかった項目をメモ**（質問票の改善に使う） |
| 40〜50分 | 「結果を出す」→ 画面を見ながら説明 | 「確定」から説明する。「推定」は条件次第、「要確認」は金額を出していない理由を説明 |
| 50〜60分 | 価格と紹介の質問 | 下記第4節 |

**やらないこと**：契約先への問い合わせ・解約手続きの代行、特定の乗換先の推薦（手数料も受け取らない）、書類の撮影・持ち帰り、入力内容や結果を生成AIに入力すること。

## 4. 最後に必ず聞く3つ

1. 「この結果に、もし知らない店がお金を払うとしたら、いくらが妥当だと思いますか？」（9,800円／19,800円／それ以上／払わない）
2. 「結果を見て、実際にやってみようと思う項目はどれですか？」→ 1か月後に実行したか聞く約束をする
3. 「知り合いのサロンオーナーさんを2〜3人ご紹介いただけませんか？」「お店の税理士さんはサロン専門の方ですか？」（紹介元につながるか）

## 5. 終わったら記録すること

- `kpi/salon_hearing_log.csv` に1行（所要時間 `diagnosis_minutes`、見直し余地の下限・上限、価格への反応、紹介の可否）
- 「回答を保存（JSON）」で保存したファイルは、**業務用のフォルダに保管し、Git にはコミットしない**（`.gitignore` 済みの `client_data/` に置く）
- 結果は「結果を印刷・PDF保存」でPDFにしてオーナーに渡す
- 質問票で分かりにくかった項目 → 次の店の前に `check.html` を直す（Claude Code に依頼。店の数字は渡さず「この項目が分かりにくかった」とだけ伝える）

## 6. この1店のあとの判断

| 結果 | 次の動き |
|---|---|
| 見直し余地が年19,800円を超え、診断が60分以内に終わった | オーナーの紹介で2〜3店に広げる。税理士の紹介をもらえたら打診（第7節） |
| 見直し余地が年19,800円を下回った | 原因を確認（もともと固定費が少ない店か、質問票で拾えていない費目があるか）。2店目で再確認 |
| 質問票に答えられない項目が多かった | 質問票を簡素化してから2店目へ |

## 7. 税理士事務所への打診はいつ、なぜ必要か

**目的は「規模」の検証。** 月利益50万円には月30件前後の診断が必要で、知人・紹介の直接営業だけでは届かない可能性が高い。サロン専門の税理士は1事務所で多くのサロンを顧問先に持つため、1件の提携が継続的な紹介につながるかを確かめたい。

**急がない。** 商品が1店で機能することを確かめてから打診する（W3以降）。最初の打診先は、協力店の顧問税理士など**紹介でつながれる事務所**を優先する（面識のない事務所に送るより話が早く、営業メールの規制も気にしなくてよい）。
