## 3. サロンオーナーへのヒアリング（30分・売り込みなし）

冒頭で伝えること：「サロンの固定費の管理実態を調べています。売り込みはしません。資料のご提出は不要です。」

| 時間 | 質問 |
|---|---|
| 0〜5分 | 店舗数・席数・スタッフ数、月商のレンジ、開業年数 |
| 5〜15分 | 毎月払っているもの（決済・予約/POS・通信・電気・集客媒体・保険・リース）を一緒に書き出す。**最後に見直したのはいつか** |
| 15〜20分 | 経営で一番困っていること（集客・人・お金）。固定費の見直しは何番目か |
| 20〜25分 | 決済・電気・通信の「無料見直し」の営業を受けたことはあるか。どう感じたか |
| 25〜30分 | 「5分の質問に答えると、見直せる固定費と金額の目安が分かる。余地が診断料より小さければ全額返金」に、いくらなら払うか（9,800円／19,800円／払わない）。月額2,980円で値上げ・更新の通知が来るサービスは必要か |

記録：`kpi/salon_hearing_log.csv`

## 4. 診断の流れ（半自動）

```
オーナーが質問票に回答（約5分・Googleフォーム想定、書類の提出は不要）
 → 回答を JSON に変換（W3は手作業、合格後にフォーム連携を自動化）
 → python3 tools/salon/fixed_cost_check.py --input answers.json --out-md report.md
 → 人が結果を確認（10分）→ 15分のオンライン説明 → レポート送付
```

- 質問票の項目は `tools/salon/samples/answers_sample.json` と同じ（第5節）
- **顧客の回答や結果を生成AIに入力しない**（数値の判定は決定論的プログラムのみ）。説明文の言い回しの調整にAIを使う場合も、店名・金額を含めない
- 当方は契約先との交渉・解約手続きの代行をしない。乗換先から手数料を受け取らない

## 5. 質問票（5分）

| # | 質問 | 使い道 |
|---|---|---|
| 1 | 店名・店舗数 | — |
| 2 | 月商（だいたい） | 決済手数料の計算 |
| 3 | 売上のうちキャッシュレスの割合 | 同上 |
| 4 | 決済サービス名とクレジットカードの手数料率、月額固定費 | 同上 |
| 5 | 使っている予約・POS・カルテ・配信・会計ツール、それぞれの月額と主な機能、直近3か月使ったか | 重複・未使用の判定 |
| 6 | 電話・ネット回線の一覧と月額、使っているか、最後にプランを見直した年 | 通信 |
| 7 | 電気代と使用量（kWh）（直近の検針票の数字） | 電気の単価 |
| 8 | 集客媒体の月額（掲載費・予約手数料など）と、その媒体経由の新規客数/月 | 集客の費用対効果 |
| 9 | 平均客単価、新規客が1年目に来る回数（だいたい）、粗利率（だいたい） | 同上 |

## 6. 紹介元（サロン専門の税理士・会計事務所）への打診

- 提案：「顧問先サロンに、固定費・集客費チェックを付加価値として提供しませんか。顧問先の手間は5分の質問票だけです」
- 条件案（テスト）：最初の3店は無料。以後は紹介手数料30%、または事務所が一括で購入して顧問先に無料提供する形（価格はテストで決める）
- 注意：顧問先の情報を事務所から受け取る場合は、顧問先本人の同意を取る。紹介料の受け取りが所属団体の規程に触れないかは事務所側で確認してもらう
