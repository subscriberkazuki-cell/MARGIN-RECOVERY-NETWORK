# 営業フロー

## 1. チャネルの優先順位（90日間）

| 順位 | チャネル | 理由 | 目標（90日） |
|---|---|---|---|
| 1 | 直接メール営業（公表アドレス・送信可否確認済みのみ） | 即日開始でき、反応データが早く取れる | 送信600件 |
| 2 | 紹介パートナー（EC支援会社・EC専門の税理士事務所・Shopify制作会社） | 信頼が移転され成約率が高い。B2B2SMB | 提携3社、紹介5件 |
| 3 | コンテンツ（運賃改定の解説記事・無料チェックリスト） | 中長期のSEO資産。毎年の運賃改定時期に需要が来る | 記事6本 |
| 保留 | Explee 等のAI営業ツール | 法令・日本語精度の確認後に小額検証 | 50件検証 |
| 不採用 | 広告、テレアポの外注、問い合わせフォームへの一斉送信 | 費用対効果が不明、または受信者の迷惑・ブランド毀損 | — |

## 2. 見込み客リストの作成手順（Agent2）

1. **候補の発見**：EC関連の公開情報（モール出店一覧、業界メディアのランキング、EC支援会社の事例ページ等）から自社ECを持つ事業者を抽出。各サイトの利用規約・robots.txt に従い、スクレイピング禁止のサイトからは取得しない
2. **規模の推定**：商品数、レビュー件数、SNSフォロワー数、送料設定から月間出荷1,000件以上かを推定（スコアの一要素。断定しない）
3. **連絡先と送信可否の判定**（特定電子メール法）
   - 連絡先は「特定商取引法に基づく表記」または会社概要に**事業者自身が公表しているメールアドレス**のみ
   - 同ページ・サイト内に「営業メールお断り」「広告宣伝メールの送信を拒否」等の表示があれば **送信不可**
   - 個人名のアドレス（担当者個人の推測アドレス）は使わない
   - 記録項目：取得元URL、取得日、拒否表示の有無、判定者
4. **スコアリング**（下表）→ 60点以上を送信対象

| 項目 | 配点 | 判定方法 |
|---|---:|---|
| 推定月間出荷数（1,000件以上） | 25 | 公開情報からの推定 |
| 送料体系（全国一律・送料無料ライン等で負担が大きい） | 15 | 送料ページ |
| 商品の形状（薄型・軽量品が多い → 小型便化の余地） | 15 | 商品ページ |
| 自社出荷か3PLか | 10 | 発送元表記・求人情報 |
| 運賃値上げへの言及（送料改定のお知らせ等） | 15 | お知らせページ |
| 意思決定者への到達性 | 10 | 代表者アドレスか窓口か |
| 業種適合（アパレル・化粧品・食品・雑貨） | 10 | 商品カテゴリ |

スコアの重みは、成約データが10件たまった時点で Finance & Risk が見直す。

## 3. 商談までの流れ

```
送信（人間承認）→ 返信分類（Agent3：興味あり／質問／不要／配信停止）
  ├ 配信停止 → 即日除外リストへ（以後どのチャネルでも送信しない）
  ├ 不要 → 終了（追客しない）
  ├ 未返信 → 7日後に1回だけ追客。以後送らない
  └ 興味あり／質問 → 15分のオンライン面談 or そのまま無料診断フォームへ
```

## 4. 無料診断 → 本監査

| ステップ | 担当 | 所要 |
|---|---|---|
| 診断申込（フォーム） | 顧客 | 3分 |
| 提出案内メール（個人情報削除の手順付き） | Agent4 → 人間承認 | 即日 |
| 出荷CSV1か月分・料金表を受領 | 顧客 | 1〜5日 |
| 監査エンジンで自動突合 | Agent5 | 数分 |
| 結果の確認・一次結果シート作成 | 人間 | 15分 |
| 結果説明（30分オンライン） | 人間 | 30分 |
| 本監査の申込（成功報酬契約） | 顧客 | — |

## 5. 紹介パートナー制度

| 項目 | 内容 |
|---|---|
| 対象 | EC支援会社、Shopify・カート制作会社、EC専門の会計事務所、EC向けコンサル |
| 報酬 | 紹介案件の当社成功報酬の20%（入金後に支払い） |
| パートナーの業務 | 紹介のみ（当社サービスの説明資料を渡す）。顧客データには触れない |
| 注意 | 士業の紹介料受取は所属団体の規程に抵触しないかパートナー側で確認してもらう。弁護士の有償紹介は受けない・しない |
