# /stock-a — 企業分析（Stock Analysis A）

対象：$ARGUMENTS

## 厳守事項
- **指定されたティッカーと決算期間を厳守**する。期間が指定されていなければ「最新の正式発表済みの四半期」とし、それが何かを最初に明記する
- **最新の正式決算・一次資料を優先**：決算短信／10-Q・10-K／8-K（プレスリリース）／決算説明資料／決算説明会トランスクリプト／有価証券報告書。報道・まとめサイトは補助のみ
- 未発表の数値を推測で埋めない。市場予想は出典（取得元と日付）を書く。取得できなければ「未取得」と書く
- 投資判断の推奨（買い・売り）はしない。判断材料を整理する

## 工程
1. **特定**：企業名、ティッカー、上場市場、会計年度の区切り、対象四半期、決算発表日を確定する（research-analyst）
2. **財務の確認**：売上、営業利益、EPS（GAAP/非GAAPを区別）、営業CF、FCF（営業CF−設備投資、定義を明記）。前年同期比・前四半期比も
3. **利益を生む事業の特定**：実際に利益を生んでいる具体的な事業・製品を特定する
4. **成長ドライバー**：原則 **TOP1〜2 に限定**。それぞれのセグメント別の売上・利益寄与を数値で示す（開示がなければ「非開示」と書き、推計する場合は推計方法を明記）
5. **中国依存度・サプライチェーン・供給制約**：中国（香港・台湾は区別して記載）の売上比率、主要供給元、供給制約・輸出規制の影響
6. **KPIと市場予想の差**：主要KPIと会社ガイダンス・市場コンセンサスの差（出典つき）
7. **バリュエーション**：PER・EV/売上・EV/EBITDA・FCF利回りなど、使った株価の日付を明記
8. **ブル・ベア要因**：それぞれ3つ以内、根拠つき
9. **Core Definition**：最後に「この会社は何で稼ぎ、何が次の成長を決めるのか」を1〜2文で定義する
10. **検証**：数値を出典と突き合わせ、計算を再確認する。quality-reviewer に審査させる（期間の取り違え、GAAP/非GAAPの混同、出典の期間ずれを重点的に）。修正は2回まで
11. **保存**：`AI_Hub/01_Projects/Investment/{ティッカー}/YYYY-MM-DD_{決算期}_A.md` に保存し、PROJECT_INDEX/MEMORY_INDEX を更新

## 出力形式
```
# {企業名}（{ティッカー}）{決算期} Stock Analysis A
- 企業名 / ティッカー / 市場：
- 決算四半期：　　会計年度：　　決算発表日：
- 主な一次資料：（URL・日付）

## 1. 財務サマリー（表：売上・営業利益・EPS・営業CF・FCF／前年同期比・前期比）
## 2. 利益を生む事業
## 3. 成長ドライバー TOP1・TOP2（セグメント別の売上・利益寄与を定量化）
## 4. 中国依存度・サプライチェーン・供給制約
## 5. KPIと市場予想の差
## 6. バリュエーション（株価の日付）
## 7. ブル要因 / ベア要因
## 8. Core Definition
## 出典一覧 ／ 未確認事項 ／ 審査結果の要約
```
