# /remember — 長期記憶への保存

保存する内容：$ARGUMENTS

AI_Hub の場所は CLAUDE.md の「長期記憶」に書かれたパス。

## 1. 何を保存するか（再利用価値があるものだけ）
| 種類 | 保存先 |
|---|---|
| 決定事項（方針・採用/不採用・価格など） | `00_Home/DECISIONS.md` に追記（日付・決定・理由・関連ノート） |
| 持ち主の判断基準・好み・NG | `00_Home/USER_PROFILE.md` の該当節 |
| プロジェクトの状況・決定 | `01_Projects/{プロジェクト}/` の該当ノート、`00_Home/PROJECT_INDEX.md` の状況欄 |
| 再利用できる知識・手順 | `02_Knowledge/{分野}/{テーマ}.md` |
| 調査結果 | `03_Research/YYYY-MM-DD_{テーマ}.md` |
| 失敗した方法と原因 | `02_Knowledge/{分野}/` の該当ノートの「うまくいかなかったこと」節 |

保存しないもの：会話の丸ごと、一時的な作業メモ、パスワード・APIキー・トークン・口座番号・他人の個人情報。

## 2. 手順
1. **重複確認**：`MEMORY_INDEX.md` と、保存先フォルダを Grep で検索し、同じテーマのノートがあれば**新規作成せずに追記・更新**する
2. **区別**：決定（確定）と仮説（未検証）を分ける。仮説には検証方法を書く
3. **出典**：調査由来の事実には URL と日付
4. **変更履歴**：過去の決定を変えるときは、古い内容を消さずに「変更履歴」節へ移し、日付と理由を書く
5. **書式**：下のテンプレート。1ノート1テーマ。関連ノートは `[[ノート名]]` でリンク
6. **索引更新**：`00_Home/MEMORY_INDEX.md` に1行（日付・種類・ノートへのリンク・1行要約）を追加。索引は新しい順、100行を超えたら古い行を `90_Archive/MEMORY_INDEX_YYYY.md` に移す
7. **報告**：保存したファイルと要約を1〜3行で報告する

## 3. ノートのテンプレート
```markdown
---
type: decision | knowledge | research | project | profile | failure
status: 確定 | 仮説 | 廃止
project: {プロジェクト名 or なし}
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
---
# {テーマ}
## 要点
## 詳細
## 根拠・出典
## うまくいかなかったこと（あれば）
## 変更履歴
- YYYY-MM-DD: 作成
```
