# /research — 出典付き調査

調査テーマ：$ARGUMENTS

## 目的
意思決定に使える、出典付きで検証済みの調査結果を作る。

## 工程
1. **問いの分解（PLAN）**：テーマを3〜7個の具体的な問いに分ける。期間・地域・対象の定義を決める。曖昧で結果が大きく変わる点だけ持ち主に1回確認し、それ以外は妥当な前提を置いて明記する
2. **過去の記憶**：`AI_Hub/03_Research/` と `00_Home/MEMORY_INDEX.md` で同じテーマの過去の調査を探す。あれば再利用し、古い部分だけ更新する
3. **収集（EXECUTE）**：research-analyst に問いを渡す。問いが独立していて多い場合のみ2体に分ける（同時2体まで）
4. **検証（VERIFY）**：重要な数値（結論を左右するもの）は出典を開いて自分でも確認する。出典の日付と対象期間を確認する
5. **反証（REVIEW）**：結論が意思決定に使われる場合は quality-reviewer に「反対の証拠・見落とし」を探させる
6. **統合（FINALIZE）**：下の形式でまとめる。修正は2回まで
7. **保存**：再利用価値があれば `AI_Hub/03_Research/YYYY-MM-DD_テーマ.md` に保存し、MEMORY_INDEX に1行追加（/remember の規則に従う）

## 品質基準
- すべての数値・固有の主張に出典（URL・公開日）。一次情報を優先し、二次情報はそう書く
- 事実／推測／提案を見出しで分ける
- 見つからなかったこと・矛盾した情報を隠さない

## 出力形式
```
# {テーマ}（調査日 YYYY-MM-DD）
## 結論（3行以内）
## 事実（表：内容・数値・期間・出典・公開日）
## 推測・解釈
## 反対の証拠・リスク
## 未確認事項・次に調べること
## 出典一覧
```
