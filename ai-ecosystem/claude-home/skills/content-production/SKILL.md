# /content-production — コンテンツ制作

依頼：$ARGUMENTS

## 共通ルール
- ブランド（株式決算予想のYouTubeチャンネル、「なんでもないもの博物館」など）ごとの口調・禁止事項は `AI_Hub/01_Projects/Content/` のノートに従う
- 投資関連の内容は、断定的な将来予測・売買の推奨をしない。数値には出典と時点を付ける
- 他人の著作物（字幕・画像・音楽）の扱いに注意し、転載ではなく要約・引用の範囲にとどめる
- 公開・投稿・アップロードは持ち主が行う。AIは下書きまで

## A. YouTube URL → ブログ記事・SNS投稿
1. **字幕の取得**：使える手段（導入済みの字幕取得ツール、持ち主が貼り付けた文字起こし、公開されている字幕ページ）で取得する。**取得できなかった場合は、取得できなかったことと理由を明記して止め**、文字起こしの貼り付けを依頼する。推測で内容を作らない
2. **分析**：要点（主張・根拠・数値・具体例）を抽出し、タイムスタンプを付ける
3. **記事構成**：検索意図に合わせた見出し構成（H2/H3）、狙うキーワード
4. **本文**：構成に沿って執筆。動画内の数値・主張は出典（動画と時刻）を示す
5. **SNS投稿案**：X・Instagram など媒体ごとに2〜3案
6. **画像**：必要な画像の指示（構図・文字・サイズ）を書く。切り出しが必要なら時刻を指定する
7. **品質チェック**：quality-reviewer に、事実の正確さ・日本語・誤解を招く表現・著作権を審査させる。修正は2回まで
8. **保存**：`AI_Hub/04_Outputs/YYYY-MM-DD_{タイトル}/` に記事・投稿案を保存

## B. 広告動画・YouTube動画の構成
1. 目的・視聴者・尺・行動喚起を決める
2. 秒単位の構成表（時間・映像・テロップ・ナレーション・音）を作る
3. 台本・ナレーション原稿・BGMの指示
4. 必要な素材（画像・図表）の一覧と指示書
5. quality-reviewer で審査 → 修正（2回まで）
6. 動画の合成・ナレーション生成など外部ツールが必要な工程は、導入済みのツールがある場合のみ。なければ手順書として出力する
