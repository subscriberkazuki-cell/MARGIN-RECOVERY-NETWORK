# /stock-b — 成長ドライバー別 競合分析（Stock Analysis B）

対象：$ARGUMENTS

## 前提
- 同じ企業の Stock Analysis A の結果（`AI_Hub/01_Projects/Investment/{ティッカー}/` の最新の *_A.md）を読み、TOP1・TOP2 の成長ドライバーを確定する。A がなければ先に `/stock-a` を実行するか、持ち主に確認する

## 工程
1. 各成長ドライバーについて、**日本・米国の上場企業**から競合候補を広めに洗い出す（research-analyst）
2. 各候補について、対象事業の売上と **全社売上に占める構成比**、顧客、利益源泉、供給能力を一次資料で確認する
3. 下の基準で採点する（各項目の根拠を1行で書く）
4. **60点未満は除外**。該当が少なければ無理に3社を埋めない（0社・1社でもよい）
5. 各ドライバーにつき最大 **TOP3**
6. quality-reviewer に、採点の根拠・構成比の出典・除外判断を審査させる。修正は2回まで
7. `AI_Hub/01_Projects/Investment/{ティッカー}/YYYY-MM-DD_B.md` に保存

## 採点基準（100点）
| 項目 | 配点 |
|---|---:|
| 成長ドライバー適合度 | 25 |
| 顧客重複度 | 15 |
| 利益源泉の重複度 | 15 |
| テーマ重複度 | 10 |
| 対象事業の重要度（全社に占める比重） | 15 |
| 市場シェア・競争力 | 10 |
| CAPEX・供給能力 | 5 |
| 地域・規制要因 | 5 |

## 出力形式
```
# {企業名}（{ティッカー}）Stock Analysis B（YYYY-MM-DD）
## 成長ドライバー TOP1：{名称}
| 順位 | 企業（ティッカー・市場） | 合計点 | 対象事業の売上 | 全社売上 | 構成比 | 主な根拠 |
（採点内訳の表：8項目×各社、根拠つき）
除外した主な候補と理由（60点未満など）
## 成長ドライバー TOP2：{名称}
（同上）
## 出典一覧 ／ 未確認事項 ／ 審査結果の要約
```
