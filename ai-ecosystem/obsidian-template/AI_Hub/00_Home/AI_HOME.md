# AI Hub

Claude Code（司令塔）が使う長期記憶。人間もここから全体を見渡せる。

| 入口 | 内容 |
|---|---|
| [[USER_PROFILE]] | 判断基準・好み・制約 |
| [[PROJECT_INDEX]] | 進行中のプロジェクトと状況 |
| [[MEMORY_INDEX]] | 保存した記憶の索引（新しい順） |
| [[DECISIONS]] | 決定事項と変更履歴 |
| [[AI_ROUTING]] | どのAI・ツールを何に使うか |

## フォルダ
- `01_Projects/` プロジェクトごとの状況・決定・メモ
- `02_Knowledge/` 再利用できる知識・手順・失敗の記録
- `03_Research/` 調査結果（出典つき）
- `04_Outputs/` 成果物（記事・レポート等）
- `05_Daily/` 日々のメモ（任意）
- `90_Archive/` 古くなった記録

## ルール
- 1ノート1テーマ。決定と仮説を分ける。出典を残す。過去の決定は消さずに変更履歴へ
- パスワード・APIキー・口座番号などは保存しない
