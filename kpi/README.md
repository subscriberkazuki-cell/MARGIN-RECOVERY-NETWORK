# KPI管理表

| ファイル | 用途 | 更新 |
|---|---|---|
| `kpi_weekly.csv` | 週次KPI（営業・監査・収益・コスト・作業時間） | 毎週金曜 |
| `pipeline.csv` | 案件ごとの進捗（送信根拠 `optin_basis` を必ず記録） | 随時 |
| `hearing_log.csv` | 初回ヒアリングの仮説検証ログ | 面談ごと |

Googleスプレッドシートに取り込んで運用し、月末にCSVでエクスポートして前提値の更新に使う。
**顧客の実データ（請求書・出荷CSV）はここに入れない。** 金額は集計値のみ。

## 主要KPIの定義

| KPI | 定義 | 標準シナリオの目標 |
|---|---|---:|
| 返信率 | 返信 ÷ 送信 | 3% |
| 商談化率 | 商談 ÷ 返信 | 50% |
| 診断実施率 | 診断 ÷ 商談 | 70% |
| 本監査転換率 | 本監査契約 ÷ 診断 | 50% |
| 削減実現率 | 効果検証完了 ÷ 本監査契約 | 80% |
| 平均月間削減額 | 検証済み月間削減額の平均 | 80,000円 |
| 1社あたり成功報酬 | 平均月間削減額 × 12 × 25% | 240,000円 |
| WATCH移行率 | WATCH契約 ÷ 削減実現 | 40% |
| WATCH月次解約率 | 解約 ÷ 月初契約数 | 4%以下 |
| 1社あたり作業時間 | 診断・監査・支援の合計 | 11時間以下 |
| 顧客獲得単価 | （営業費＋紹介料）÷ 本監査契約数 | 30,000円以下 |
| 「確定」指摘の誤り率 | 誤り件数 ÷ 確定指摘件数 | 0% |

前提値の更新：`finance/simulate.py` の `EC_STANDARD` を実績値に置き換えて再実行する。
